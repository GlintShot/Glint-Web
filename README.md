# Glint Web

[![Use Glint](https://img.shields.io/badge/Use%20Glint-Open%20editor-c9a227?style=for-the-badge&labelColor=1a1c1f)](https://glint-f0h.pages.dev)

**The browser editor for store screenshots.**

Take real app screens → polish them into Play Store and App Store frames → export a ZIP ready to upload.  
No account. No server. Everything runs in the browser.

## Why Glint Web

Store listings need sharp, on-size frames. Glint Web is the place you design them: templates, device chrome, captions, colors, then one export.

| | |
|---|---|
| **Drop & go** | Drop PNGs or import a screenshot folder |
| **Templates** | Play Store & App Store packs (phone, tablet, TV, Wear, Chromebook, iPhone, iPad) |
| **Frames board** | 1–10 store-size artboards - not an infinite canvas |
| **Polish** | Captions, colors, device bezels, scale, rotation, layers |
| **Export** | Store PNG ZIP · editable `.glint` project · handoff for on-device preview |

**Real UI only** - never invent App Store screenshots.

## Ways to use it

### 1. Manually
Open the editor with the badge above → import screens → pick a template → tweak → export ZIP.

### 2. With an AI / coding agent
Point your agent at Glint Web. It can drive the editor in a **headless browser**, apply templates, and export - or work **Copilot-style** beside you while you watch frames update.

### 3. Locally (developers)

```bash
npm install
npm run dev
```

Open http://localhost:5173
