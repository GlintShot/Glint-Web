# Graphics attributions

Recolor slots for Glint-authored SVGs use preview-default fills `#FF6B4A` (a), `#FFD166` (b), `#FFF7F2` (c)
so the sidebar matches the canvas. Legacy `#A10000` / `#B10000` / `#C10000` still map to a/b/c.

## Theme behavior

- **Mono** (Lucide icons, brands, shapes): black on light chrome, white on dark chrome.
- **Color** (Humaaans, stickers, hands, charts, badges, color icons, blobs): exact colors — no grayscale/invert.

## Removed

**unDraw** scene illustrations (phones-in-a-scene, desks, laptops, landscapes) were removed —
they fight store screenshot compositions and added picker weight.
